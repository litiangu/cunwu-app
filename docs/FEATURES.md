# 核心特性

## 🧠 健康分引擎

- 📊 **二维加权模型**：`score = 0.55 × D1 + 0.45 × D2`，纯 Kotlin 实现，不依赖 Android 与 Room，可被 JVM 单测完整覆盖
- 🎯 **四档评级**：优（≥85）/ 良（≥70）/ 中（≥50）/ 差，首页与分析页同源同色
- 🔍 **子分拆解**：分析页健康卡以同心多环呈现，每个维度一环，弧长即为该维度得分占比
- 🧾 **纯函数设计**：`computeHealthScore(items, dailyBudgetAnchor)` 输入输出皆为纯数据，易测易复用
- ✅ **8 个 JVM 单元测试**覆盖空集合、全售出、净投入为负等边界

## ✂️ 端侧智能抠图

- 🤖 **ormbg（ISNet 架构）** on Google **LiteRT**，176 MB TFLite 模型随仓库分发，纯 CPU 推理，不依赖 GMS
- 🎨 **贴纸化后处理**：α 硬边 → 原图全分辨率合成 → 白色描边 + 边缘投影
- 🧽 **多级形态学流水线**：两段式二值化 → 开运算去噪 → 均匀背景先验 → 看穿区种子生长 → 洪泛填洞 → 最大连通域 → 十字核边缘内缩
- 🐛 **19 轮专项修复**（`fix01` ~ `fix19`），逐个攻克白边断裂、轮辐楔形区残留、近圆形大洞误抠等真实缺陷
- 🔒 **Git LFS** 存储模型；`.gitattributes` 已配置 `filter=lfs`，克隆时务必拉取 LFS 内容

## 🏠 三视图物品管理

- 📋 **模式 A 时间轴**：按购入月份分组，80dp 行高，适合回溯"我什么时候买了什么"
- 🌊 **模式 B 瀑布流**：等高 2×2 网格卡片，适合视觉浏览
- 🖼️ **模式 C 陈列馆**：36dp 圆图紧凑网格，适合快速扫一眼
- 🔎 **搜索 + 筛选排序**：状态（使用中 / 未使用 / 已售出）× 排序（日期 / 金额，升降序）
- 👆 **左滑操作**：三视图统一的侧滑编辑 / 删除
- 🗂️ **软删除 + 回收站**：删除进回收站，30 天自动清理，每行显示剩余天数

## 📈 分析页

- 💍 **资产结构**：资产总额 = Σ(购入 + 附加) − Σ(变现)，拆为「净持有」与「已回流资金」双卡
- 🗺️ **分类资产分布**：按 6 个预置分类（数码 / 电器 / 家具 / 工具 / 运动 / 交通）聚合
- 📉 **趋势卡**：近 30 天支出走势，支持分月 / 全部切换
- 🚨 **超支警示条**：任一分类超月度限额即置顶，点击平滑滚动到预算卡
- 🎖️ **物品排行榜**：陪伴最久 / 收益最高 / 日均成本最高

## 💰 预算体系

- 📅 **每日预算锚点**：D2 的分母基准，默认 ¥100 / 天
- 📆 **月度预算基准**：近 30 天支出 vs 月度预算
- 🏷️ **分类月度预算**：逐类独立限额，空值表示不设限

## 🔒 隐私与本地化

- 🚫 **零网络权限**：`AndroidManifest.xml` 仅声明 `VIBRATE`，无 `INTERNET`
- 🕶️ **隐私模式**：一键把首页与分析页全部金额替换为 `****`，柱高与比例仍按真实值计算，不破坏视觉节奏
- 💾 **含图备份**：导出为单个 `.zip`（`backup.json` + `images/`），支持还原 / 分享 / 存到手机
- ⏰ **备份提醒**：超期（3 / 7 / 14 天可调）在首页提示，30 秒自动消失，不做每日打扰
- 🗑️ **回收站**：进入时自动清理超过 30 天的物品，先删图文件再删数据库行，不留孤儿文件

## 🎨 设计系统

- 🎨 **Aura Minimalist** 设计语言，主色 `#FF5500`
- 🔤 **Manrope 可变字体**（`FontVariation.Settings` 驱动，SemiBold / Bold 真实生效）
- 🌗 **深色模式三档**：跟随系统 / 浅色 / 深色，自研双 `ColorScheme` + `CompositionLocal`
- 🔘 **24 / 12 圆角体系**，卡片底色 `surfaceContainerLowest` + 软阴影
- 📳 **震动反馈**：轻点、切换、保存、左滑操作均有触觉回馈，可一键关闭
